# 数据与权限

## 本机存储

- API Key 默认放在浏览器会话存储。勾选“记住 Key”后保存在该浏览器的扩展本地存储，未自行加密，不跨设备同步。
- 两种存储均限制为扩展可信页面；课程内容脚本不能直接读取 Key。
- 可在设置页删除 Key。开始托管前由使用者在浏览器登录课程平台；公开插件不附带账号、密码或自动登录工具。

## 发往模型服务的数据

请求直接发送到使用者选择的 API 服务。文字题可能发送题干和选项；图片题可能发送必要的题目截图；视觉入口定位可能发送课程页面的可见文字和截图。

截图中可见的个人信息也可能包含在内。请自行选择信任的服务并查看其数据处理政策。插件不读取 Cookie 或密码输入框，不内置遥测、远程代码或另一个转发后端。

模型目录仅从同一服务来源读取，不跟随跨域分页链接或重定向。更换来源时需要提供该服务的 Key。

## 浏览器权限

- `storage`：保存接入信息与运行状态。
- `activeTab`、`scripting`：识别和操作用户打开的课程页面。
- `debugger`：按需截图题目、处理受浏览器激活限制的播放/课程入口。使用时 Edge 可能显示调试提示。
- 课程平台站点权限：仅在学习通与中国大学 MOOC 注入课程适配。
- 可选 API 站点权限：用户配置服务时，申请访问所选服务。不会向这些 API 网站注入课程脚本。

## 仓库与安装包

真实浏览器目录、课程诊断记录、个人配置、凭据工具、开发规划和旧安装包均不进入公开仓库或源码包。安装包只包含明确列出的扩展资源、说明和无真实内容的检查摘要。
