# 常见问题

## 模型连接

- 401：核对 Key 与服务地址是否对应。
- 403：核对模型/业务空间权限。
- 404：核对 Base URL 和模型 ID；仅目录接口不可用时可手填模型。
- 429：核对额度与服务限流。
- 请求参数不兼容：确认服务支持 OpenAI 兼容 Chat Completions；可尝试关闭高级设置中的 JSON 参数约束。
- 文字能用、图片失败：另选支持图片输入的模型并执行图片测试。

模型目录里的条目不一定都支持聊天、图片或 JSON 输出。先测试再用于课程。

## 播放与截图

保留课程页面。浏览器拒绝自动播放时手动点一次播放器；截图或播放仍失败时，检查是否有其他开发工具占用调试连接。不要同时对同一课程运行多个自动控制工具。

## 长时间没有反应

托管期间如果页面超过设定时间（默认 45 秒）没有任何进展，插件会先自检：课程或章节全部完成则停止并提示；否则自动刷新页面并继续托管。可在设置中关闭“自动刷新恢复”或调整无响应时长。登录失效、验证码和需本人确认的声明不会被刷新绕过。

页面有未提交题目或正等待提交确认时，会保留作答，不自动刷新。完成或自行保存当前练习后，再继续后续内容。

## 已有解析但没有自动选答

0.8.4删除了阈值、严格模式和低分重试按钮。更新扩展并刷新课程页后，点击“开始托管”或“解析并自动作答”；模型自检或多模型复核完成后直接选答，按自动提交和确认设置继续。

旧的confidenceGate和minConfidence配置会被忽略。低分、缺少自评分或模型分歧不单独阻止作答。接口权限、调用上限、没有有效答案或页面控件无法操作时会显示具体原因。用户在模型处理期间修改的答案会保留。

## 平台显示回答错误

平台明确判错后，会记录并排除这次答案，再启动自检和辅助复核。只有复核后的新答案才可再次提交；同一已拒绝答案或整组提交会被阻止。修改仅作用于插件提交过且尚未被用户改动的字段。

最多自动纠正2次。若仍被平台拒绝、所有模型坚持已拒绝的答案，或无法确定课程中的特定语境，会暂停并显示原因。重新开始也会保留本次浏览器会话中的拒绝记录。

如果平台只提示整份练习有错误，插件会重新复核各题，保留具体错题尚不明确的状态。平台旧错误提示尚未清除时，会等待本次返回结果。

启动前页面已有错误提示时，会先记录当前选项并独立复核。获得不同的有效答案后，自动改选并提交；复核期间用户改变的字段会保留。旧提示不会直接把当前选项记为平台已否定的答案；没有发生改答时仍会阻止原样重交。

## 视频中途弹出题目

学习通播放器会在视频中途弹出随堂题。插件定时检测弹窗，暂停抢播、作答、点击“提交”和“继续”后恢复播放。若某类弹窗未被识别，请反馈弹窗截图和去掉敏感信息的页面结构。

## MOOC待办

“需本人处理”会显示具体章节、原因和入口。点击“前往处理”后，插件保持停止；本人按平台要求完成测验或回复，之后可点“复查本页”。

已提交/待评分/成绩记录可清除对应测验待办；当前讨论中检测到平台确认的本人回复可清除参与待办。已浏览、草稿和其他人的回复不算本人完成。浏览器重启后的课程状态仍需在平台核对。

## 反馈问题

提供插件版本、浏览器版本、平台名称、复现步骤和去掉查询参数的页面路径。请勿提交 Key、Cookie、账号密码或真实课程内容。涉及敏感信息的问题参阅 [安全反馈](../SECURITY.md)。

## 解析答案与页面选项不同

0.8.1按可见字母匹配控件，点击后读取平台真实选中状态，提交前再核对一次。控件没有选中证据、字母重复或页面延迟改变选择时，会停止提交并显示原因。更新扩展后请刷新课程页，避免旧内容脚本继续运行。

模型完成复核后会采用有效答案并继续填写。“页面当前选择”单独显示实际检测到的内容。平台精确否定记录只剩一个可选项时，会直接改选，并显示“依据：平台判错后的唯一剩余选项”。

## 多选题提示选项点击未通过核对

0.8.5修复学习通章节测验与作业中的多选选中状态识别、页面重绘后的旧节点点击，以及异步状态尚未更新便重复点击的问题。会按字母勾选目标答案、清除多余选项，确认整个集合一致后自动提交。

请重新加载扩展并刷新答题标签页，确认弹窗版本为0.8.5。无需恢复阈值或重新配置模型；若仍失败，请提供具体页面类型及选项区域截图，便于检查控件结构。

## 考试或作业文本框没有写入

0.8.3增加新版作业题块和富文本支持。确认“自动处理已打开的考试和作业”与“自动填写”已开启，并重新加载扩展、刷新答题页。UEditor通过编辑器接口写入并同步隐藏的提交字段，不以页面仅显示文字作为完成依据。

“字数不足”表示正文没有满足题干或输入框要求，会先进入复核；这是平台的正文要求。编辑器尚未就绪时会等待重试；本人在模型请求或写入前改动内容会保留。提交成功和暂存成功分别处理，只有平台明确提交成功才显示本次作答完成。

## 判断题或多空题仍无法作答

0.8.6优先读取学习通明确题型，识别已适配的对错图标；填空会把空位数量交给模型并复核缺项，普通与富文本混用时按页面顺序填写。重新加载扩展并刷新题目页面后生效。

连线、拖拽、组合题及公式专用编辑器需单独适配；具体范围见[答题逻辑核查记录](ANSWER_ADAPTERS.md)。这些控件限制与自评分无关，当前版本没有分数门槛。

## 本题保存与连线

0.8.7支持已适配的原生/Chosen下拉连线，以及分录/资料题的文本空位。逐项核对真实值后继续；遇到本题保存按钮时先等待局部保存，再翻页或整页提交。关闭自动提交会保留填写结果，不额外点击服务器保存。

“页面未确认本题保存”表示没有收到已适配的保存状态，插件不会据此重复发送或宣称整份作业已提交。明确的保存失败最多重试两次。选项与下拉的忙碌状态会等待响应，超过等待上限时显示具体原因。
